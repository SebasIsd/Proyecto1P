# Proyecto Manejo y Configuracion de Software (Parcial 1)

## Descripción

Este repositorio contiene un sitio web básico de e-commerce desarrollado con HTML, CSS y JavaScript. Incluye páginas para productos, carrito, checkout, contacto y detalles, con imágenes de productos en diferentes colores.

### Objetivos
- Crear una interfaz de usuario funcional para un sitio de e-commerce.
- Mostrar productos con variaciones de color mediante imágenes.
- Implementar funcionalidades básicas como carrito y simulación de envío.

## Estructura del Proyecto

- **/css/**: Archivos de estilos (CSS).
- **/img/**: Imágenes de productos en diferentes colores.
- **/js/**: Scripts JavaScript
- **/lib/**: Bibliotecas o dependencias (si aplica).
- **/mail/**: Archivos relacionados con simulación de envío (si aplica).
- **/scss/**: Archivos de estilos en SCSS (preprocesador CSS).
- **/.gitignore**: Configuración para ignorar archivos en Git.
- **/cart.html**: Página del carrito de compras.
- **/checkout.html**: Página de checkout.
- **/contact.html**: Página de contacto con simulación de envío.
- **/detail.html**: Página de detalles de productos.
- **/index.html**: Página principal.
- **/shop.html**: Página de tienda.
- **README.md**: Este archivo.

## Instalación y Configuración

### Requisitos Previos
- Un navegador web moderno (Chrome, Firefox, etc.).
- Editor de texto (VS Code, Sublime Text, etc.).
- Git instalado para clonar el repositorio.

### Pasos para Clonar y Usar
1. Clona el repositorio:
   ```
   git clone https://github.com/SebasIsd/Proyecto1P.git
   cd Proyecto1P
   ```

2. Abre `index.html` en tu navegador para ver la página principal.

## Uso
- Navega por las páginas como `shop.html` para ver productos.
- Usa `cart.html` y `checkout.html` para simular compras.
- Consulta `detail.html` para ver detalles de productos con imágenes en diferentes colores.
- El archivo `contact.html` simula el envío de correos.
