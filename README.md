# 🛍️ Proyecto: Manejo y Configuración de Software (Parcial 1)

## 📖 Descripción

Este proyecto es un **sitio web de e-commerce** desarrollado con **HTML, CSS y JavaScript**.  
Incluye páginas para productos, carrito, checkout, contacto y detalles, con imágenes de productos en diferentes colores 🎨

### 🎯 Objetivos
- 💻 Crear una interfaz de usuario funcional y atractiva.
- 🖼️ Mostrar productos con variaciones de color mediante imágenes.
- 🛒 Implementar funcionalidades básicas como carrito y simulación de envío.
- 📬 Simular un formulario de contacto funcional.

## ⚙️ Instalación y Configuración

### 🔧 Requisitos Previos
- 🌐 Navegador web moderno (Chrome, Firefox, Edge, etc.)
- 🧠 Editor de texto (VS Code recomendado)
- 🧰 Git instalado para clonar el repositorio

### 🚀 Pasos para Clonar y Ejecutar
1. Clona el repositorio:
   ```bash
   git clone https://github.com/SebasIsd/Proyecto1P.git
   cd Proyecto1P
   ```

2. Abre el archivo `index.html` en tu navegador.

---

## 💡 Uso
- Explora la tienda en `shop.html` 🛍️  
- Agrega productos al carrito en `cart.html` 🛒  
- Simula el proceso de compra en `checkout.html` 💳  
- Visualiza los detalles de productos en `detail.html` 🔍  
- Usa `contact.html` para enviar un mensaje de contacto (simulación) 📩
